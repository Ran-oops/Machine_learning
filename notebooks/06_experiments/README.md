# 实验笔记 (Experiments)

本目录包含各种机器学习实验和探索性代码，**主要使用 scikit-learn 库**。

## 说明

这些笔记是早期学习阶段的实验记录，内容涉及：
- 传统机器学习算法（逻辑回归、随机森林、AdaBoost 等）
- scikit-learn 库的使用
- 特征工程技巧（如 one-hot 编码）
- 简单分类任务实践

## 与主项目的关系

**主项目 (`notebooks/01_basics/` 到 `05_regularization/`)**：
- 使用 PyTorch 实现深度学习算法
- 跟随《动手学深度学习》教程
- 从零实现神经网络

**本目录 (`06_experiments/`)**：
- 使用 scikit-learn 的实验性代码
- 探索不同算法和库
- 学习记录和草稿

## 建议学习顺序

如果你是深度学习初学者，**建议先完成 `01_basics/` 到 `05_regularization/` 的笔记**，掌握 PyTorch 基础后再来看这些实验笔记。
